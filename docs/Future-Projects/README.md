# Future Projects

This folder separates planned, proposed, conditional, and access-dependent work from projects that already contain an implementation artifact.

Nothing grouped here should be interpreted as completed work unless its individual status is later updated and supporting evidence is added.

## Grouped future-project documents

- [Automotive Audio Implementation Roadmap](../02_Automotive_Audio_Implementation_Roadmap.md) — staged plan for CAN simulation, conceptual system architecture, DSP simulation, vehicle measurement, and later implementation
- [Immersive Audio Evaluation Part 2: SigmaStudio DSP Project](../03_Immersive_Audio_Evaluation_Part_2_SigmaStudio_DSP_Project.md) — planned measurement-guided DSP follow-up
- [Conditional Car DSP Installation and Portfolio Validation Plan](../04_Conditional_Car_DSP_Installation_and_Portfolio_Validation_Plan.md) — conditional, funding-dependent vehicle DSP development scenario

These documents remain available as development plans, but they are intentionally separated from [Project 1: Real-Time DSP Prototype in Pure Data](../05_Real-Time_DSP_Prototype_in_Pure_Data.md), which already includes an implementation artifact and a documented Version 2 revision.
